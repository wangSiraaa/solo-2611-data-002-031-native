# 固定息合约本地估值工具

单币种、固定本金、固定票息合约的本地估值与折现曲线校准工具。纯 Python 3.11 +
NumPy/SciPy 实现，不依赖交易系统、数据库或外部日期库。输入全部来自 `fixtures/`
下的合成 JSON（十进制字符串），输出为自描述 JSON 报告。

## 支持范围与边界

**支持**

- 单币种、固定本金（到期一次还本）、固定票息；
- 计息边界按月滚动生成，支持月底约定（end-of-month）；
- 付款日按提供的假日表做**修正后续（Modified Following）**调整；
- 日计数统一 **ACT/365 Fixed**（闰年分母仍为 365）；
- 估值日落在付息期中间时区分应计利息、全价（dirty）与净价（clean）；
- 简单计息存款 + 固定息基准债券净价的曲线自举校准；
- 负利率（折现因子允许大于 1，不会因此被拒绝）。

**明确不支持（收到即报结构化诊断，不静默处理）**

- 浮息、分期还本/摊还、非常规重置等条款（按字段名关键字与白名单双重拦截）；
- 多币种；
- 未声明的残缺期（起息日到到期日不是票息月数整数倍时拒绝，不偷偷补一期）；
- 远期起息存款、估值日后无现金流的校准工具；
- 曲线末支点之外的外推定价；
- 多估值日收益归因、交互图表、版本服务。

## 使用

```sh
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/pip install -r requirements-dev.txt   # 仅测试时需要

.venv/bin/python -m fixedincome price      # 校准 + 目标合约全价/净价/应计
.venv/bin/python -m fixedincome scenario   # 按 plan 扰动报价、重新校准、逐现金流价差
.venv/bin/python -m fixedincome inspect    # 曲线支点、拟合残差、逐笔现金流明细
```

可选参数：`--fixtures-dir`（默认 `fixtures/`）、`--output-dir`（默认 `reports/`）、
`--contract ID`（可重复，限定目标合约）。报告写入输出目录：
`price_report.json`、`scenario_report.json`、`inspect_report.json`；业务错误写
`diagnostic.json` 并以退出码 2 返回。

## 方法

### 1. 计息日程（计息边界与付款日严格分开）

1. 从起息日按 `coupon_months` 逐月滚动，得到**未调整**的计息边界；`end_of_month`
   为真且基准日是自然月末时，目标日也取目标月自然月末；
2. 若滚动边界永远无法恰好等于到期日（下一跳越过到期日），判定为未声明残缺期，
   抛 `schedule_error`，诊断含最后一个合法边界与越过点；
3. 付款日对每个期末边界单独应用修正后续：遇周末/假日顺延，顺延续跨月则回退到
   当月最后一个营业日。计息边界本身不调整；
4. 票息 = 本金 × 票息 × ACT/365 当期年份分数；还本只在最后一期，金额等于本金。

### 2. 应计与价格

- 估值日 ≤ 起息日，或合约全部付款日已过：应计为 0；
- 估值日落在计息期 `[accrual_start, accrual_end)` 内：
  应计 = 本金 × 票息 × ACT/365(accrual_start → 估值日)；
- 付款日 **≤ 估值日** 的现金流视同已付（含估值日当天），不计入现值；
- 全价 = Σ 未来每笔现金流 × 付款日折现因子；净价 = 全价 − 应计。

### 3. 折现曲线与校准

- 曲线变量为**连续复利零息利率** r(t)，折现因子 DF(t) = exp(−r·t)，
  t 为距估值日的 ACT/365 年份分数；
- 支点取各校准工具的到期付款日；支点间对零息利率**线性插值**；首支点之前按首
  支点利率平坦外推（t=0 时 DF=1）；末支点之外**拒绝外推**，报 `out_of_range`；
- 按到期日排序自举：
  - 简单计息存款：DF(T) = 1 / (1 + r·ACT/365(T))，解析得到支点利率；
  - 债券：全价 = 净价 + 估值日应计，到期支点利率用 `scipy.optimize.brentq`
    对“剩余现金流现值 − 全价”求根，债券与目标合约共用同一日历与现金流规则；
- 校准后对全部工具**重新报价**并报告残差；情景分析完整复制报价集、修改报价后
  重新执行整个自举流程，不允许直接改最终价格或只替换一个折现因子。

### 4. 负利率

求根区间为连续复利零息利率 `[−0.5, +1.0]`，对称覆盖负利率；任何环节都不施加
DF ≤ 1 的约束。存款为负简单利率时解析得到 DF > 1，属合法结果。

## 数值容差（明确声明，不以求根器“成功”作为验证）

| 容差 | 值 | 用途 |
| --- | --- | --- |
| `SOLVER_XTOL` | 1e-12 | brentq 绝对收敛容差 |
| `SOLVER_RTOL` | 4·eps ≈ 8.88e-16 | brentq 相对收敛容差（机器精度下限） |
| `RESIDUAL_TOL` | 1e-8 | 校准后重新报价的残差上限（货币单位/每 100 本金，存款为利率差） |
| `PRICE_TOL` | 1e-9 | 净价+应计=全价、逐现金流 PV 求和=全价、情景价差合计核对 |

求根返回后还会显式重算残差并与 `RESIDUAL_TOL` 比较；超容忍即判校准失败。
无解（求根区间两端残差同号/非有限）、重复支点、支点不足、范围外等情形都有
专门的诊断码与细节字段，绝不返回任意初值算出的价格。

```

  dates.py       日期算术、ACT/365、营业日日历与修正后续

  curve.py       折现曲线、brentq 自举校准、残差核对
  valuation.py   全价/净价/应计、已付剔除、范围外拒绝
  reports.py     报告组装、情景重新校准与逐现金流价差

  cli.py         price / scenario / inspect 命令
tests/           51 个 pytest 用例（见下）
```

## 验证用例（`tests/`，共 51 个）

- 月底跨假日：修正后续顺延续跨月回退（2027-01-31 周日 → 01-29）、周中假日链；
- 计息边界 vs 付款日不混淆，残缺期拒绝且不补期（含越过点诊断）；
- 估值日处息期中：应计手工核算、期末边界当天视同支付、起息日零应计；
- 负利率：DF > 1 被接受、负利率存款与高净价债券可校准、负曲线估值；
- 已知曲线小报价：用一条给定零息曲线生成存款/债券报价，校准后残差 < 1e-10，
  支点利率被还原；
- 独立现金流求和核对净价/全价关系（`PRICE_TOL`）；
- 到期已付合约（含估值日当天付款）：settled、零价格、无需曲线；
- 错误还本（amortization）/浮息字段/负票息/零本金：校验拒绝；
- 不可校准输入：极端报价无解诊断（含 bracket 两端残差）、空市场、远期存款、
  重复支点、无未来现金流债券；
- 范围外合约与支点不足：`out_of_range` 诊断；
- 情景：完整重拟合、逐现金流价差合计等于全价差、扰动报价被精确重新拟合、
  缺失报价诊断；
- CLI 端到端：三命令报告结构、诊断文件与退出码 2。

```sh
.venv/bin/python -m pytest tests/ -q
.venv/bin/python -m pyflakes fixedincome/ tests/
```
