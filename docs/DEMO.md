# 真实 PTY 演示记录

所有记录由 `demo/run_demo.py` 在真实 PTY 中生成；每条场景运行结束后，由
**独立程序** `tools/verify_db.py` 只读检查 SQLite。助手本身不读取数据库，
也不使用独立校验结果做判断。

复现：

```sh
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python demo/run_demo.py
```

产物位置 `demo/records/<场景>/`：

| 文件 | 内容 |
|---|---|
| `faults-run.json` | 该场景启用的一次性故障（运行后会被应用消费） |
| `legacy.sqlite` | 场景独立数据库（三个初始记录 + 写入历史） |
| `assistant.log` | 助手控制台全过程 |
| `report.json` | 计划、动作、逐屏快照、保存反馈、回读值、最终处置 |
| `raw/*.ansi` | 原始 ANSI 字节，仅审计，不参与判断 |
| `verifier.log` / `verify.json` | 独立程序看到的 items/history |

`demo/records/index.json` 汇总全部场景。

## 场景一览

| # | 场景 | 一次性故障 | 关键状态 | 独立校验 |
|---|---|---|---|---|
| 01 | 正常保存 + 退出后回读 | — | `confirmed`, `confirmed` | 现值=计划，观察写入 1/1 |
| 02 | 无变化记录不保存 | — | `unchanged`, 历史 0 | 未写入 |
| 03 | 预期旧名称不符 | — | `old_name_mismatch`，停在查询 | 未写入 |
| 04 | 编码查不到 | — | `not_found`，停在查询 | 未写入 |
| 05 | 修订冲突 | `conflict_before_save_once` | `conflict`，重新查询报 `铅笔-外部修改` rev2 | A001 未按计划写入 |
| 06 | 未知弹窗 | `unknown_prompt_once` | `unknown_popup`，现场保留，后续 `not_attempted` | 未写入 |
| 07 | 保存被业务规则拒绝 | `reject_save_once` | `rejected`，A002 继续 | A001 未写入 |
| 08 | 查询暂不可用 | `query_unavailable_once` | 第 2 次查询成功，`confirmed` | 现值=计划 |
| 09 | 成功提示前断线 | `drop_after_save_once` | `confirmed_current`（只确认当前值） | 现值=计划 |

## 关键证据摘录

### 01 正常保存（同一会话内查询 → 编辑 → 保存 → 回车 → 重新查询）

保存后屏幕（来自 `report.json` 的逐屏快照）：

```
01|资料终端 | 编辑
05|名称: 中华铅笔 [尚未保存]
06|单位: 支 [尚未保存]
07|价格: 1.50 [尚未保存]
19|保存成功；请重新查询确认
22|回车返回查询
```

退出编辑后回读：`{'name': '中华铅笔','unit': '支','price': '1.50','revision': 2}`。
只有回读一致才标 `confirmed`。

### 05 修订冲突（不覆盖）

```
19|保存冲突: 修订号已变化，请重新查询
22|回车返回查询
```

助手回车退出编辑后**重新查询**，报告记录 `铅笔-外部修改`、修订号 2；
独立校验显示 A001 的“计划值写入条数”为 0，没有把计划值覆盖进去。

### 06 未知弹窗（停止并保留现场）

助手依次发送 `e` → 名称 → 单位空行 → 价格，随后屏幕出现：

```
18|异常弹窗: E97 操作条件需要人工确认
22|只允许 X 退出本次操作
```

检测到该行后**不再发送任何按键**：不按回车、不按 B、不 SIGTERM，整批停止，
A002 标为 `not_attempted`（未发送任何按键）。独立校验确认 A001/A002 均未写入。
报告中的最后一个屏幕快照就是上图的现场；`no_keys_after_stop: true` 标明停止后
没有再发按键。

### 09 成功提示前断线（PTY 断开）

动作记录：`edit-A001:save` 发送 `s` 后立刻 `PTY 断开`（应用在提交后
`os._exit(0)`，成功提示尚未输出）。助手**重启终端**、按编码查询：

```
04|编码: A001
05|名称: 中华铅笔
07|价格: 1.50
08|修订号: 2
```

现值全等于计划值 → 标 `confirmed_current`，并在报告中写明
“这不证明恰好一次写入，仅证明当前值正确”。

## 断言与边界

- 演示刻意**不做**“拼接 ANSI 历史搜保存成功”：所有识别都基于 `pyte` 重建的
  80×24 当前屏幕。
- 未适配其它布局；固定 80×24、单一布局。
- 回读/写入历史条数**不能**证明恰好一次写入；报告中保留该免责声明。
- 一次仅运行一个场景，各自使用独立 DB 与故障文件，避免状态串扰。
